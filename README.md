# 崇德志工社網站

崇德志工社的官方網站與內容管理系統。MVP 採用 Next.js、Supabase 與 Vercel。

## 本機開發

需求：Node.js 20.9 或更新版本。

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)。

## 指令

```bash
npm run dev    # 啟動開發伺服器
npm run lint   # 執行 ESLint
npm run build  # 建立 production build
npm run start  # 啟動 production server
```

產品與技術規格位於上一層的 `docs/` 目錄。
